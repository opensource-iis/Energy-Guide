# Energy-Guide
> Originally a submission for IIS TechFest!

> A website with practical advice for conserving energy and improving performance on your devices, in three categories: **Hardware**, **Software**, and **Internal Settings**.

##  Categories

**Hardware**

- Dedicated advice for monitors, GPUs, mice and keyboards

**Software**

- Basic and everyday settings for games and programs

**Internal Settings**

- 4 different sections, including basic and advanced settings

## Contributing

Fork the repo → create a branch (`git checkout -b feature/new-tip`) → commit → push → open a Pull Request. 

Keep tips accurate, practical, and in the right category.

*Small changes add up. Save energy, extend your devices, protect the planet.*
